# RE:VERSE — 시간이 돌아가는 숲

## 프로젝트 소개

A의 시간좌표를 거슬러 살아가는 여행자의 경험을 탐색하는 3D HTML 사고실험입니다. 순방향으로 숲에 들어가 사람이 달리다 뒤로 넘어지는 모습을 보고, 포탈을 통과해 같은 사건을 역방향으로 관찰합니다. 세계의 시간이 되감겨도 여행자의 경험과 기억은 계속 쌓입니다.

## 핵심 특징

- **포탈로 바뀌는 시간 방향:** 순방향에서 시작해 포탈을 통과할 때마다 진행 방향이 바뀝니다.
- **되감기는 사건:** 달리던 사람이 배를 위로 향해 넘어집니다. 역행 중에는 누운 자세에서 일어나 달리기 전 상태로 돌아갑니다.
- **인물별 기억 연결망:** 왼쪽 위 패널에서 여행자와 순방향 인물의 기억을 비교합니다. 장면 속 사람을 클릭하거나 터치해 관찰 대상을 바꿀 수 있습니다.
- **유지되는 여행자의 기억:** 순방향 경험은 금색, 역방향 경험은 민트색 연결로 표현합니다. 포탈을 지나도 이전 경험은 사라지지 않습니다.
- **직접 걷거나 자동 산책:** 데스크톱 이동과 모바일 조이스틱을 지원합니다. 동작 줄이기 설정에서는 자동 산책과 재생을 멈춘 상태로 시작합니다.
- **단일 파일 실행:** Three.js와 글꼴을 포함한 `index.html`을 브라우저에서 바로 열 수 있습니다.

## 아키텍처

Three.js가 숲과 인물을 렌더링하고, Canvas 2D가 추상적인 기억 연결망을 그립니다. 별도 서버나 백엔드는 없습니다.

| 파일 | 역할 |
| --- | --- |
| `index.html` | 실행·배포용 단일 HTML |
| `source/shell.html` | 화면 구조, 스타일, 조작 UI |
| `source/world.js` | 3D 세계, 카메라, 입력, 시간 진행, 소리 |
| `source/experience.js` | 포탈 통과, 넘어지는 인물, 선택과 기억 시각화 |
| `source/build.py` | 소스·엔진·글꼴을 `index.html`로 결합 |
| `assets/` | 포함된 엔진, 글꼴 및 각각의 라이선스 |
| `tests/experience.cjs` | Playwright 기반 브라우저 동작 검사 |

세계 상태는 A의 시간좌표 `t`에 따라 결정됩니다. 여행자의 누적 경험 시간 `personalTime`과 방향별 기억 `forwardMemory`, `reverseMemory`는 별도로 관리합니다. 따라서 세계가 과거로 진행해도 여행자의 누적 경험은 증가합니다. 코드의 `observer` 값 `a`/`b`는 여행자의 현재 순방향/역방향 모드를 뜻합니다.

## 시간·엔트로피·기억의 설정

A는 A의 시간좌표가 증가하는 방향으로 살아갑니다. 역행하는 B는 같은 좌표가 감소하는 방향을 자신의 미래로 경험하며, 기억도 그 방향으로 쌓입니다. 체험의 여행자는 처음에는 순방향으로 살다가 포탈을 통과하면 B의 방향으로 진행합니다.

**B 개인의 엔트로피 증가는 B 자신의 미래를 기준으로 한 표현입니다.** B가 살아가는 방향으로 B 개인의 엔트로피는 증가하지만, 우주 나머지 부분의 감소량이 더 크므로 B를 포함한 우주 전체 엔트로피는 감소한다고 가정합니다. A의 미래 방향으로 B의 역행 구간을 읽으면 B의 엔트로피와 기억은 감소하는 순서로 배열됩니다.

전체와 개인의 엔트로피 변화가 반대라는 조건과 A·B의 미래 방향이 반대라는 조건은 독립된 배경 가정입니다. 현재 코드는 엔트로피의 수치를 계산하지 않고, 이 설정에 따른 사건의 방향과 기억의 누적을 시각화합니다.

| 관찰 대상 | 순방향으로 진행할 때 | 포탈을 통과해 역방향으로 진행할 때 |
| --- | --- | --- |
| 여행자 | 순방향 경험 축적 | 기존 기억 유지 + 역방향 경험 축적 |
| 순방향 인물 A | 더 나중의 기억 상태를 관찰 | 더 이른 기억 상태를 관찰 |

A의 연결망이 줄어드는 모습은 역행하는 여행자의 관찰입니다. A 자신이 망각을 체감하는 것은 아닙니다. 패널의 노드와 연결은 경험의 흔적을 단순화한 이미지이며, 실제 뉴런 수나 엔트로피 양을 나타내지 않습니다.

## 실행과 조작

상단에서 **기본 모드 / 각본 여행자 시점 / A 시점**을 선택합니다. 모드를 바꿔도 각 모드의 진행 위치와 기억이 보존되며, 처음부터 버튼은 현재 모드만 초기화합니다.

- **기본 모드:** 기존 자유 이동과 자동 산책입니다.
- **각본 여행자 시점:** 순방향으로 이동하다 경험 시간 24초에 포탈을 통과합니다. 같은 세계의 과거로 이동하고, 경험 시간 27~29초에 공중제비를 한 번 한 뒤 30~32초에 A 쪽으로 돌아서서 32~34초에 앉습니다. 48초까지 A를 바라보며 포탈 이전 기억에 역방향 경험이 더해집니다.
- **A 시점:** A의 눈높이에서 달리다 넘어지고, 포탈에서 떨어진 위치에서 여행자의 동작을 관찰합니다. A 시간 24초 이전에는 같은 여행자의 순행·역행 구간이 금색·민트색 인물로 함께 보입니다. 역행 인물의 동작은 앉아 있음 → 일어서기 → 돌아서기 되감기 → 거꾸로 공중제비 → 포탈 순서입니다. 미니맵은 역행 여행자를 기본 선택하며 두 인물을 클릭하거나 패널 버튼으로 선택할 수 있습니다.

두 인물은 충돌해서 소멸하지 않습니다. A 시간 24초의 포탈에서 이어지는 하나의 세계선입니다. 그 이후 A 시간에는 여행자가 없으므로 미니맵에 관찰 대상이 없다고 표시하고, A와 세계는 48초까지 계속 진행합니다. A가 역행 여행자를 관찰할 때는 포탈 이전 기억 24초가 유지되고 역행 경험만 줄어드는 순서로 보입니다. 여행자 자신에게는 두 구간의 기억이 연속해서 쌓입니다.

WebGL을 지원하는 브라우저에서 `index.html`을 열고 **들어가기**를 누릅니다. 기본 자동 산책은 넘어지는 인물을 보여준 뒤 포탈을 통과합니다.

| 입력 | 동작 |
| --- | --- |
| `W A S D` 또는 방향키 | 걷기, 자동 산책 해제 |
| 왼쪽 `Shift` + 이동 | 빠르게 걷기 |
| 화면 드래그 | 둘러보기, 자동 산책 해제 |
| `P` 또는 재생 버튼 | 일시 정지 / 재생 |
| 포탈 통과 | 시간 방향 전환 |
| 사람 클릭·터치 / 패널의 사람 아이콘 | A의 기억 관찰 |
| 패널의 시계 아이콘 | 여행자의 기억 관찰 |
| 자동 산책 아이콘 | 자동 산책 켜기 / 끄기 |
| 처음부터 버튼 | 시간과 기억을 초기화하고 새 여정 시작 |

모바일에서는 왼쪽 조이스틱으로 걷고 화면을 드래그해 둘러봅니다. A의 시간좌표 범위는 0~48초이며, 경계에 도달하면 재생이 정지합니다. 새 여정을 시작하려면 처음부터 버튼을 누릅니다.

## 수정과 빌드

`source/`의 파일을 수정한 뒤 프로젝트 루트에서 Python 3으로 실행합니다. 외부 Python 패키지는 필요하지 않습니다.

```bash
python3 source/build.py
```

빌드는 `index.html`을 덮어씁니다. 생성된 HTML을 직접 수정하면 다음 빌드에서 변경 내용이 사라집니다.

## 검증

Node.js에서 `playwright` 모듈과 Chromium을 사용할 수 있는 환경에서 실행합니다.

```bash
node tests/experience.cjs
node tests/story.cjs
node tests/story-view.cjs
```

별도 위치에 설치되어 있다면 해당 경로를 지정합니다.

```bash
NODE_PATH=/path/to/node_modules CHROMIUM_PATH=/path/to/chrome node tests/experience.cjs
```

검사는 순방향 시작, 넘어짐, 인물 클릭, 포탈 통과, 이전 기억 유지와 역방향 기억 증가, A의 기억 감소, 초기화, 모바일과 동작 줄이기 모드, 런타임 오류 및 외부 네트워크 요청 유무를 확인합니다. 스크린샷은 `/tmp/opposite-*.png`에 저장합니다.
